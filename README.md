# sagarika.work — rebuilt

Portfolio site for Sagarika Kanchibail, Senior UX Researcher.
Rebuilt from a full clone of the live site (Nov 10, 2026) as a React app
with **Material UI** for layout/typography/forms and **BoardUI** components
for chips, stat cards, accordions, tabs, breadcrumb and tables.

## Stack

- Vite 8 + React 19, hash routing (works on GitHub Pages with no server rewrites)
- Material UI 9 (`@mui/material`, Emotion) — theme in `src/theme.js`, same palette
  and fonts as the original: Bricolage Grotesque headings, Karla body,
  ink `#1e1c1b`, rust `#b4552d`, page `#f1f1f1`
- BoardUI 0.5.9 (free Starter, MIT) — components vendored under
  `components/`, `styles/`, `utils/` via `npx boardui add`
- Tailwind CSS 4 (required by BoardUI)

## Content — faithful to the live site

- Home, About, Contact + all 6 case studies, in the original order:
  Migration Readiness, Living With Legacy, AI Processing + Citations,
  Rolling Research, Enhancing Bulk Actions, Data Validation Function
- All copy, figures (47 images) and the resume PDF come from the clone in
  `../source/sagarika.work/` — nothing was invented or reworded.
  The structured content lives in `src/data/content.js`, generated by
  `../parse_content.py` from that clone (315 content blocks).
- Known inconsistency carried over as-is from the live site: the migration
  sample is given as n=120 (homepage), n=150 screened (case study) and
  n=123 (resume PDF). The rebuild does not pick one over the others.
- Contact form posts to the same FormSubmit endpoint as the original
  (`sagkanb3@gmail.com`).

## BoardUI usage

- `Chip` — method tags on project cards and case pages
- `StatCards` — homepage at-a-glance (all numbers from the site) and the
  impact stats on the Bulk Actions / Data Validation case pages
- `Accordion` — the 7 accordions on Living With Legacy and 10 on Rolling Research
- `Tabs` — Work filter: All / ServiceNow / Reltio
- `Breadcrumb` — case-study trail (patched: `next/link` replaced with a
  plain `<a>`, this is a Vite app, not Next.js — see `components/base/breadcrumb/breadcrumb.tsx`)
- `Table` — the At-a-Glance key/value rows on case pages
- The BoardUI `DataTable` demo was **not** used: it ships fake customer
  data, which does not belong on this portfolio.

## Develop

```sh
npm install
npm run dev
npm run build   # outputs dist/ (base './', works under any repo name or custom domain)
npm run preview
```

## Deploy (GitHub Pages)

Push this folder to the repo, then enable Pages with the included workflow
(`.github/workflows/deploy.yml` — builds with Node 22 and publishes `dist/`).
`public/CNAME` keeps the `sagarika.work` custom domain; remove it if the
site should live at `<user>.github.io/<repo>/` instead.
